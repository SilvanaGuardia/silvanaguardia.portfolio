Dashboard de Ventas de Perfumes con Looker Studio

Este proyecto presenta un completo dashboard de ventas de perfumes desarrollado en Looker Studio. Utilizando dos bases de datos distintas, una para perfumes de hombres y otra para perfumes de mujeres, el dashboard proporciona una visualización clara y detallada de las tendencias de ventas, preferencias de los clientes y rendimiento de los productos. Este proyecto ilustra la capacidad de Looker Studio para integrar y visualizar datos de manera efectiva, facilitando la toma de decisiones informadas en el sector de la perfumería.
