Visualización de Datos con PowerBi

Creamos un Dashboard con la data que tenemos de supermarket_sales, tenemos 1000 filas, y 17 columnas, buscaremos que cliente es el que compra más, ciudades con más ventas, secciones con mayor volumen de ventas.


Los datos contienen las siguientes columnas:

• ID de factura
• Sucursal
• Ciudad
• Tipo de cliente
• Género
• Línea de productos
• Precio unitario
• Cantidad
• Impuesto 5%
• Total
• Fecha
• Hora
• Pago
• Total de ventas
• Porcentaje de margen bruto
• Ingresos brutos
• Clasificación
