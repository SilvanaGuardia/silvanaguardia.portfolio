Descripción del Proyecto

Este proyecto consiste en un análisis detallado de la rotación de personal, utilizando un conjunto de datos de Kaggle. El objetivo principal fue identificar patrones y factores clave que contribuyen a la rotación de empleados para ayudar al departamento de Recursos Humanos a desarrollar estrategias de retención más efectivas.

Resultados Obtenidos

  • Identificación de los principales factores que influyen en la rotación de personal (e.g., salario, satisfacción laboral, horas extras, etc.).
  • Desarrollo de visualizaciones claras en Tableau que permiten al departamento de RRHH monitorear las tendencias de rotación.
  • Provisión de información actionable para diseñar iniciativas de retención de talento más dirigidas y eficientes.

Herramientas Utilizadas

  • Python para la limpieza, análisis exploratorio de datos y modelado estadístico.
  • Librerías de Python: Pandas (para manipulación de datos), Matplotlib y Seaborn (para visualización).
  • Tableau para la creación de un dashboard interactivo que resume los hallazgos clave.

Descripción del Proyecto

Este proyecto consiste en un análisis detallado de los datos de ventas de perfumes de mujer en la plataforma eBay. El objetivo principal es identificar patrones de venta, productos populares, tendencias de precios y preferencias de los clientes, con el fin de proporcionar información valiosa para optimizar las estrategias de venta y mejorar la comprensión del mercado de perfumes en línea.

Resultados Obtenidos

  • Identificación de las principales tendencias y patrones de ventas a lo largo del tiempo (ej. picos estacionales, días/horas de mayor venta).
  • Análisis de los perfumes, marcas y categorías más vendidas en eBay.
  • Desarrollo de visualizaciones claras e interactivas en Tableau para monitorear el rendimiento de las ventas y detectar oportunidades.

Herramientas Utilizadas

  • Excel para la limpieza de datos, organización y análisis preliminar.
  • Tableau para la creación de un dashboard interactivo y visualizaciones que resumen los hallazgos clave.
